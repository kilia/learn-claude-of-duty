Al-Bakr 市场 · 静态合并批次目录

来源：src/world/level.js 的 SURF + Builder → _finalize → Geo.mergeAll。 每个非空材质桶合并成 1 个 Mesh = 1 次 draw。 文档自称 ~18 draws；完整 SURF 表有 21 个键 （空桶不产出网格；湿斑等可能极稀）。 这是关卡静态本体，不含 props / 天气 / 武器 / UI。

批次切分规则：按表面键（材质语义）分桶，不按“会不会动”。 同一键下所有几何共享一份 MeshStandardMaterial 克隆（开 vertexColors），世界 UV + 可选 domain warp，再写磨损顶点色。 base 字段把桶名重定向到库材质（如 wet→concrete、 rooffelt→gravel），再用 roughness / env 覆盖做出差异。 distant 是唯一 own:true——不用库图，用关卡自生成的远景立面贴图。
材质参数摘自 materials.js DEFS；贴图算法摘自 textures.js 对应 gen*。Fallback 色来自 level.js FALLBACK（库缺失时的应急外观）。
