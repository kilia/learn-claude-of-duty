# 贴图生成算法

本文整理 Operation Blackout 过程式 PBR 贴图系统的设计目标、完整流水线、算法族分类、三种代表性材质（`concrete` / `reefer_panel` / `tile`）的逐步算法与美术意图，以及配套的可视化 demo 网页。

源码入口：`src/render/textures.js`（配方与 `_emit`）、`src/core/util.js`（RNG / Noise）、`src/render/materials.js`（绑定与着色器扩展）。

可视化资产目录：`survey/texture_pipeline/`。

---

## 1. 设计目标与核心原则

### 1.1 为什么全程过程式

关卡不加载外部贴图资产。同一整数种子必须复现同一字节，才能支撑截图 A/B 验证。因此：

- 随机一律走 `GAME.RNG`（mulberry32）；项目禁用 `Math.random()`
- 贴图在 **CPU** 上写入 `Float32Array`，再量化为 `Uint8ClampedArray`，上传为 `THREE.DataTexture`
- `textures.js` 不创建 Canvas / WebGL context；Canvas 2D 只用于关卡里的字标、印记、人脸等真正需要光栅化的地方

### 1.2 Height-first

**先造一张可平铺高度场，再派生法线 / AO / 粗糙度 / albedo。** 共享同一高度源的通道不会互相打架；磨损读起来像物理结果，而不是画上去的污渍。

几乎每种配方内部顺序：

1. **宏色调** — 低频 fbm，避免纯平色
2. **材料结构** — Worley / 脊状裂缝 / 剪切条纹 / 显式格子 / 正弦波 / 纱线表…
3. **由高度驱动的磨损** — 低处积垢、高处磨边；可选弹坑 / 刮痕戳记
4. **色度风化** — `chromaFields` + `applyChroma`（damp / bloom / iron / bio + wash）
5. **粗糙度叙事** — 与高度同一故事：通行处抛光、湿处近镜面、锈处哑光

每张配方还有一个 `bump` 旋钮：法线强度按场内平均梯度归一到目标均值坡度 **0.42**，避免某种材质默默比邻居高十倍浮雕。

### 1.3 可平铺与 Nyquist 钳制

- **环面采样**：噪声坐标绕回，场本身周期闭合，不靠镜像或边缘混接
- **频率钳制**：`maxFreq = floor(size/3)`，Worley `maxCells = floor(size/5)`，防止微分后法线变成闪烁碎屑
- **可选 deband**：抹掉行/列均值条带，压测平铺指标；砖缝 / 波纹 / 织纹等强结构材质会关掉或部分关掉

### 1.4 脏污在哪里

贴图负责材料本体与中尺度风化。关卡几何再用**顶点色**写湿 / 垢 / 磨边——**脏污主要在顶点，不在贴图**。下游 `materials.js` 再注入 triplanar、随机平铺、RNM 细节法线、POM 等。

## 2. 完整生成流水线

```
seed (ctx.seed ⊕ hash(name))
  └─ Gen(size, seed)                    可平铺噪声工具箱
       │
       ├─ Surf 通道缓冲                 h / cr,cg,cb / al / ro / me
       │
       └─ recipe.gen(g, S)              按材质配方写满通道
            │
            ├─ [可选] deband()          抹掉行/列均值条带（反 tiling）
            │
            └─ _emit(g, S)              高度 → 全套贴图
                 │
                 ├─ clamp height → [0,1]
                 ├─ AO = blur(h)−h（双尺度腔体，非 1−h）
                 ├─ 轻度 box blur(h) → Sobel → normal（bump → 均值坡度 0.42）
                 ├─ Bayer 抖动量化到 8-bit
                 ├─ 打包：albedo(sRGB) | normal | ORM(R=AO, G=rough, B=metal)
                 └─ displacement = 1/4 分辨率高度
                      │
                      └─ THREE.DataTexture → cache → materials.js 绑定
```

### 2.1 启动与调度

`TextureLibrary.build()` 按优先级预生成：

- 默认：`ORDER`（market 共享约 28 种）
- `levelId === 'harbor'`：先 `HARBOR_ORDER`（17 种），再共享集
- 质量档决定分辨率：`hero` 1024/512，`std` 512/256，`small` 256/128
- 每种之间让出帧，加载条可刷新

### 2.2 `_emit`：从高度到 GPU 贴图

| 通道 | 算法要点 |
|---|---|
| **Normal** | 对轻度低通后的高度做环面 Sobel；按场内平均梯度把 `bump` 归一到 0.42 |
| **AO** | `blur(h)−h` 双半径腔体近似（不是 `1−h`，否则每个凸起都被压黑）；按正腔体均值自适应增益，地板约 0.34 |
| **ORM** | 一张纹理同时供 `aoMap` / `roughnessMap` / `metalnessMap`（R=AO, G=rough, B=metal） |
| **Displacement** | 高度下采样到 `size/4` |
| **量化** | 8×8 Bayer 抖动，减轻 8-bit 色带 |

特例：`detail_normal` 只出法线；`foliage` / `chainlink` / `steel_grate` 带 alpha。

`masonry` / `masonry_rubble` 在 `materials.js` 本地生成，不进 `textures.js` 的 `RECIPES`。

## 3. 噪声原语与通用算子

### 3.1 噪声基底

| 原语 | 算法思路 | 典型用途 |
|---|---|---|
| `lattice` + `addNoise` | 环面周期随机格 → 五次 Hermite 插值可分上采样 | 一切 value-noise 的地基 |
| `fbm` / `fbmA` | 多 octave 振幅按 `gain` 衰减求和；`fbmA` 允许 `fx≠fy` | 宏观色调、拉丝、波纹 |
| `ridged` | `v=(1−\|n\|)²`（sharp 再平方）分形叠加 → 细亮脊线 | 裂缝、釉面龟裂 |
| `worley` | 格内抖动特征点；每像素 F1 / F2 / cell **id** | 骨料、气孔、砂粒、崩边中心 |
| `drip` | 向下（或向上）指数衰减扫掠 | 锈泪、冷凝流挂、污渍 |
| `shear` | 整数斜率逐行平移；整数斜率保持环面可平铺 | 拖把膜、抛光通道、斜划痕 |
| `blur` | 可平铺可分 box blur | AO、法线前低通 |

### 3.2 图像算子

| 算子 | 含义 |
|---|---|
| `sstep(e0,e1,x)` | Hermite smoothstep；允许 `e0>e1` 做反向斜坡 |
| `tint` | `lerp(A, col, t)` 染色 |
| `shade` | `A *= k` 乘法明暗 |
| `desat` | 向亮度拉饱和度 |
| `tintL`（色度层内部） | 先染色再按 keep 拉回原亮度——**只动色度不动明度** |
| `punchScrapes` | RNG 折线几何笔刷：局部削高度，同步改 albedo / roughness |
| `punchCraters` | 不规则多瓣碗状弹坑；可选唇缘与烟灰 |
| `chromaFields` | 五个低频 fbm：damp / bloom / iron / bio + tx 边缘打碎场（约 20cm–2m 墙面风化尺度） |
| `applyChroma` | 四轴门控染色 + wash 降饱和，打破「单色灰度贴图」感 |
| `deband` | 抹行/列均值偏差 |

## 4. 算法族分类

下面 10 类是「主结构算法」。几乎每种还会叠加 fbm 色调、chroma、磨损戳记。

### A. 多尺度 FBM + Worley 骨料 / 气孔

**思路：** 低频 fbm 定浇筑/抹光分区 → Worley 画露出的骨料与气孔 → ridged 裂缝 → 高度决定污垢与抛光 → 可选弹坑/刮痕。

`concrete`, `asphalt`, `dirt_ground`, `stone`, `plastic`, `dock_concrete`, `wet_concrete`

`wet_concrete` / `dock_concrete` 共用码头板逻辑；湿版抬高局部水位与镜面。

### B. 显式模板 / 模板化结构 + 噪声填充

**思路：** 确定性几何模板写高度骨架，再在格子内用 fbm/Worley 填表面；关节用 smoothstep 做成**断续**而非贯穿直线。

| 材质 | 模板特征 |
|---|---|
| `concrete_wall` | 7 道模板木纹 + 断续对接缝 + 聚类气孔 + 对拉螺杆孔 |
| `brick` | 12×4 顺砌；每层重排砖长/灰缝；`hash2i` 逐砖色与剥落 |
| `tile` | 4×4 釉砖格 + 抖动缝 + 单砖釉面 |
| `corrugated_metal` / `corrugated_roof` | 正弦波纹 + 锌花 Worley + 槽底锈 |
| `deck_plate` | 抖动胶囊防滑凸起 |
| `reefer_panel` | 9 片百叶 + 冷凝流痕 |
| `painted_line` | 热熔标线磨损到混凝土 + 玻璃珠 |
| `gun_polymer` | 模压防滑纹 / 点纹 / 分模线 |

### C. Worley 细胞板 / 网裂纹（plate-crack）

**思路：** Worley 的 **F2−F1** 形成板边界；用 cell id 阈值整板脱落；剥落区与底材同源。

`plaster`（石灰皮 + 龟裂板网 + 剥落露灰浆）

### D. 多级 Worley 颗粒床

**思路：** 几档 cell 密度叠成「大石 / 小石 / 粉料空隙」；cell id 定色；高度 = 颗粒凸起 − 空隙。

`gravel`, `rubble`, `sand`（主结构更偏各向异性风纹，Worley 做卵石点缀）

### E. 分层氧化 / 涂层剥落（金属叙事）

**思路：** 基板 → 氧化阶段 mask（bloom → scale → pit）→ `drip` 锈泪 → 高处露金属、低处积锈 → metalness 随氧化下降。

`rusted_metal`, `painted_metal`, `gun_metal`, `ship_hull`, `container_*`, `rubber_fender`

### F. 条带 / 年轮参数几何（木材）

**思路：** 显式木板分区 → 拱形/正弦「教堂纹」年轮 → 顺纹各向异性 fbm → 端面/接缝加深。

`wood_plank`

### G. 纱线布局织造（thread layout）

**思路：** `threadLayout` 造不规则经纬宽度表 → 每像素查纱 → 经纬 sin 冠高构成平纹/斜纹/浮长；条纹边界落在纱线边界；织纹主要在高度与光泽。

`fabric`, `cloth_canvas`, `sandbag`, `cloth_olive` / `cloth_tan`（防撕裂格点）

### H. 解析周期结构 + Alpha 镂空

**思路：** 解析式距离场/相位；镂空写 alpha；高度只服务可见实体。

`chainlink`, `steel_grate`, `rope`, `foliage`（叶图章图集）

### I. 低频起伏 + 薄膜 / 表皮细节

**思路：** 几乎无宏结构；用扭曲、尘膜、刮痕、毛孔、细纹决定可读细节。

`glass`, `skin`, `rubber`, `sea_water`, `tarpaulin`, `detail_normal`

### J. Materials 侧本地砌体（非 textures.js）

**思路：** 床缝高度归一化累积保证环面闭合；乱石/粗琢；可选石灰抹面剥落。

`masonry`, `masonry_rubble`（`materials.js` → `_genMasonrySet`）

## 6. 深度拆解：`concrete`（无定形浇筑面）

**算法族 A。** 代表性「纯噪声堆叠」配方：没有显式格子，靠多尺度 fbm + Worley + ridged + 几何戳记讲浇筑、磨损、潮湿的故事。

### 6.1 美术意图

- 底板是调色板里真正的**中性灰** `#9a958c`；iron 色度权重刻意压到 **0.45**，避免整场景被暖渍染成同一米色族
- 通行区水泥浆磨掉露出骨料；低处/缝/孔积垢；高处扬尘
- 湿斑更暗、粗糙度逼近镜面（`lerp → 0.04`）
- 大斑 stain 打破 4×4 平铺读成网格的风险
- 粗糙度用 10–40cm 连贯区（burnish / chalk），不用频宽只剩 2 texel、进 mip 就死的 grit 当「变化」

### 6.2 噪声原料

| 层 | 调用 | 作用 |
|---|---|---|
| macro | `fbm(3,4,0.58)` | 浇筑 / 抹光大区 |
| med | `fbm(13,4,0.5)` | 中尺度起伏与明暗 |
| fine | `fbm(90,3,0.5)` | 表面 chatter |
| grit | `fbm(280,2,0.5)` | 微粒（高度用；粗糙度叙事已不用它） |
| agg | `worley(44)` | 骨料：F1=距中心，id=石色三档 |
| pit | `worley(150)` | 气孔中心 |
| crack | `ridged(5,5,sharp)` | 裂缝网 |
| stain / damp | fbm | 色斑 / 潮湿 |
| C.* | `chromaFields(200)` | 四轴风化 + tx |

### 6.3 派生 Mask

```
expose = sstep(0.40, 0.70, 0.62·macro + 0.38·med)   // 磨损露出区
stone  = sstep(0.52, 0.14, agg.F1)                    // 细胞中心 = 石子
hole   = sstep(0.26, 0.05, pit.F1) × sstep(0.30, 0.55, med)
ck     = sstep(0.84, 0.995, crack)                    // 裂缝芯
```

### 6.4 高度叠加（每步 = 原图 ⊕ Noise）

| 步 | 运算 | op |
|---|---|---|
| H0 | `0.60` | 常数底板 |
| H1–H4 | `+(layer−0.5)·amp`（macro/med/fine/grit） | **中心化加法**（不抬整体均值）→ base slab |
| H5 | `+ stone·expose·0.135` | **掩码加法**抬骨料 |
| H6 | `− hole·0.24` | **减法雕刻**气孔 |
| H7 | `− ck·0.20` | **减法**裂缝槽 |
| H8 | `punchScrapes(14)` | 折线几何笔刷 |
| H9 | `punchCraters(5)` | 不规则碗状弹坑 |

### 6.5 Albedo 叠加

| 步 | 运算 | op |
|---|---|---|
| A0 | fill `#9a958c` | 常数 |
| A1 | 按 Worley id 三档石色 · `stone·expose` | lerp 染色 |
| A2 | 抹光区偏水泥浆 | tint |
| A3 | `× (0.86+0.28·med)` | 乘法明暗 |
| A4 | 低处/缝/孔积垢 | tint grime |
| A5 | 高处扬尘 | tint dust |
| A6 | stain 大斑（concreteDk / sandDk） | tint |
| A7 | 潮湿压暗 | shade |
| A8 | `applyChroma`（iron 0.45, wash 0.62） | 保亮度色度 |
| A9–10 | scrapes / craters 染色 | 刮痕露浅骨料；坑露水泥+烟灰 |

### 6.6 Roughness（同像素并行）

```
r  = 0.72 + (med−0.5)·0.24
r −= burnish·0.44 + stone·expose·0.18
r += chalk·0.34 + hole·0.12 + low·0.12 + dusty·0.18
r  = lerp(r, 0.04, wet)    // 湿 ≈ 镜面
metalness = 0
```

## 7. 深度拆解：`reefer_panel`（冷藏柜百叶）

**算法族 B。** 代表性「解析几何骨架 + 噪声风化」：百叶缝必须是能看见深度的开口，而不是画上去的黑线。

### 7.1 美术意图

- **9 片百叶 + 3 道竖向加强筋**：相位 `bf = frac(y·9)`，`gap = sstep(...)` 是真实缝洞（注释原话：只剩 3 texel 宽的百叶会读成百叶帘）
- 叶片有 tilt：上沿更亮/更高，暗示倾角
- 冷凝珠落在**冷叶片正面**，再经 `drip` 纵向流下；缝唇可起霜
- 掉漆露出裸铝；低处积垢；螺栓是几何戳记（3×3），同时改高度 / 颜色 / 粗糙度 / 金属度

### 7.2 结构与噪声

| 层 | 类型 | 作用 |
|---|---|---|
| macro / med / fine | fbm | 壳体大色调、面板 chatter、微起伏 |
| cond / condZ | Worley + fbm | 冷凝珠中心与结露区 |
| dirtN / chipN / streakN | fbm / fbmA | 污垢、掉漆、流痕破碎 |
| seedM → runs | `drip` | 纵向水流 |
| gap / face / tilt / rib / bf | **STRUCT** | 百叶相位、缝、正面、倾角、加强筋 |

### 7.3 高度阶段

| 步 | 运算 | op |
|---|---|---|
| H0 | `0.30` | 常数底板 |
| H1 | `+ face·(0.28+tilt·0.10)` | 加法 · 百叶几何 |
| H2 | `+ rib·0.035` | 加法 · 加强筋 |
| H3–H4 | `+(med/fine−0.5)·amp` | 中心化加法 |
| H5 | `+ bead·0.012` | 冷凝珠 |
| H6 | `stampBolts` | 3×3 螺栓戳记 |

### 7.4 Albedo / Roughness 要点

- A0 用港区专用色 `HPAL.reefer`
- 缝洞：tint + shade，缝被当成洞而不是黑线
- chip → 裸铝；grime 跟低处；wet = bead+runs；frost 在缝唇；再 chroma；最后螺栓染色
- 粗糙度叙事：漆面 / 湿 / 霜 / 裸铝 / 螺栓头对比——湿与霜把局部推向更光滑

## 8. 深度拆解：`tile`（釉砖格 + 单砖釉变）

**算法族 B。** 代表性「解析格子 + 逐砖 hash + 跨格通行场」。`materials.js` 把该材质的随机平铺偏移量化到 `[4,4]`，**格数不能改**，否则勾缝会被切断。

### 8.1 美术意图

- **性格来自烧成梯度与磨损，不是颜色抽奖**——逐砖色域刻意收窄，否则地板读成棋盘
- **Lippage**：铺在不平找平层上，一块砖比邻居高约一毫米；斜射光抓住台阶
- 磨损落差（bevel / craze / rub）刻意很浅——夸张会让程序化瓷砖变成充气枕头
- 勾缝是**另一套高度场**按 `groutM` lerp 进来（砂粒 + 被耙掉的缺失），不是在砖上挖黑槽
- 釉是关卡里最光滑的东西（rough≈0.18），勾缝最粗糙（≈0.94），被走出来的通道卡在中间——磨损在斜射光下也能读出来
- 每块砖用自己的旋转 + UV 平移采样源噪声，避免 4×4 复读同一块图案

### 8.2 噪声原料（16 层）

| 层 | 调用 | 作用 |
|---|---|---|
| mottle | `fbm(40)` | 釉面本体（按砖旋转采样） |
| macro | `fbm(3)` | 缝 X 抖动 + rub 门控 |
| fine | `fbm(210)` | 微起伏 |
| groutN / groutAgg | fbm / Worley | 勾缝表面与砂粒 |
| crack / crackB / ckMask | ridged / fbm | 细裂纹、跨砖大缝、大缝门控 |
| craze | `ridged(80,sharp)` | 釉面龟裂网 |
| chipC / speck | Worley | 面崩中心、釉下坯点 |
| dirtN / lay / traffic | fbm | 污垢、瓦工手感、通行路径 |
| mop / pol | `shear(fbmA)` | 拖把膜、脚底抛光带 |
| chroma | `chromaFields(3300)` | 五轴风化 |

### 8.3 解析结构与 Mask

**结构：**

- `tiles = 4`，`cell = size/4`
- 逐缝参数表：`hash2i → jpX/jwX/jdX · jpY/jwY/jdY`（位置偏移、缝宽、脏污种子）——缝宽不等是它不像 CAD 的原因
- 逐砖：`rot ∈ {0..3}`，`offset(tOX,tOY)` → 采样索引 `si`

**Mask（节选公式）：**

| Mask | 公式要点 | 含义 |
|---|---|---|
| groutM | `1 − sstep(0.7,1.7,ex)·sstep(0.7,1.7,ey)` | 距缝/缝宽 → 勾缝十字带 |
| bevel | `sstep(1.7,3.2,min(ex,ey))` | 砖沿圆角釉 |
| cchp | 角点极坐标 + hash 门控（约 12.5% 角崩）+ 双频 wob | 缺角 |
| traf / mopM / polish | 重映射 + 通行调制 | 通行磨损、拖把膜、抛光带 |
| cz | 高阈值 craze[si] × 逐砖 th4 | 釉面龟裂 |
| rub | `(1−bevel)(1−groutM)(0.30+traf·1.3)·sstep(macro,th2)` | 釉从砖沿磨穿露坯 |
| ck | 细裂纹 ∪ ckMask 门控的大缝 | 裂纹并集 |
| chip | Worley 中心 + 近砖沿更易崩 | 面崩 |
| broken | `th3 > 0.90` | 约 10% 整砖缺失 → 找平层 |

### 8.4 高度阶段

| 步 | 运算 | op |
|---|---|---|
| H1 | `0.72 + (th−.5)·.026 + (th4−.5)·.010 + mottle[si]·.010 + fine[si]·.004` | 中心化加法 · lippage |
| H2 | `H −= (1−bevel)·.005·(1−groutM) + cz·.005 + rub·.004` | 掩码减法 · 浅磨损 |
| H3 | `H −= ck·.030 + chip·.040 + cchp·.046`；broken → 覆盖 | 减法雕刻 + 条件覆盖 |
| H4 | `lerp(H, 0.684+groutN·.022+gAgg·.012−gLoss·.028, groutM)` | 勾缝高度场混合 |

### 8.5 Albedo 阶段

| 步 | 运算 | 要点 |
|---|---|---|
| A1 | `lerp(brickD, plasterDk, 0.15+th·0.60)` → tint | **窄色域** kiln lot |
| A2 | 砖内角度 θ 的 firing ramp + mottle | 乘法明暗 + tint |
| A3 | speck 二选一上色；cz 填脏污 | 龟裂靠脏东西才看得见 |
| A4 | cchp/rub/traf/mop/polish/broken/ck/chip 叠层 | tint / desat / shade |
| A5 | 勾缝砂浆 + agg / sandDk / grime | 勾缝是材料，不是黑线 |
| A6 | `applyChroma`（iron 1.1, wash 0.42） | 终色 |

### 8.6 Roughness / Normal

```
r ≈ 0.18
  + ck/chip/cz/cchp/rub/traf …
  − mopM − polish
  → lerp(…, 0.94…, groutM)     // 釉 ↔ 勾缝
```

Normal：对最终高度轻度低通后 Sobel（图册中为示意实现）；正式 `_emit` 另做 bump 归一与 Bayer。

## 9. 贯穿所有配方的通用层

1. **环面 Value Noise 上采样** — 任意分辨率可平铺  
2. **Height → Normal / AO / Roughness 派生** — 通道物理相关  
3. **四轴色度风化** — 打破单色灰度感  
4. **损伤戳记** — 弹坑、刮痕跨缝环绕  
5. **`drip` 流挂** — 锈/污/冷凝纵向传播  
6. **`deband`** — 压测平铺（结构材质慎用）  
7. **Bayer 抖动量化** — 减 8-bit 色带  

**一句话：** 种子 → 可平铺噪声工具箱 → 配方写 height-first Surf →（可选 deband）→ Sobel / 腔体 AO / ORM 打包 → DataTexture；材质按主结构分成十族，再统一套上色度风化与高度派生。
