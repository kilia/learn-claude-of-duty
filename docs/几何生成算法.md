# 几何生成算法

Operation Blackout 的几何全部由代码在启动时合成，零外部模型。本文汇总本仓库中若干代表性几何管线：**树干、布料与风动、市场关卡合并批次与材质、炼油厂储油罐、Bayon 雕像人脸**，以及配套的交互式 wireframe demo。

相关源码主要位于：

| 主题 | 主要源文件 |
|------|------------|
| 通用拼装 / 磨损 | `src/world/level.js`（Builder、merge、顶点色） |
| 材质与磨损着色 | `src/render/materials.js` |
| 贴图配方 | `src/render/textures.js` |
| 雨林树干 | `src/world/level_jungle.js` |
| 雪原布料风动 | `src/world/props_snowbound.js` |
| 炼油厂储罐 | `src/world/level_refinery.js` |
| 废墟 Bayon 脸 | `src/world/level_ruins.js` |

Demo 目录：`survey/mesh_pipeline/`（需本地 HTTP 打开，依赖 `vendor/three.global.js`）。

## 1. 总体架构

### 1.1 原子 → 桶 → 合并 → 网格

关卡几何的标准流水线：

1. **几何原子**  
   `bevelBox`、圆柱 `cyl`、扫掠管 `tube` / `limb`、高度场、浮雕盒 `reliefBox`、回转体、环形面等。按尺寸缓存，避免重复构建。

2. **Builder 材质桶**  
   每件几何写入 `{ geometry, matrix, tint/wear/... }`，按**表面键**（如 `plaster`、`tank`、`sandstone`）分桶，而不是按“会不会动”分桶。

3. **`Geo.mergeAll`**  
   桶内所有件变换到世界坐标后合并成一份 `BufferGeometry`。  
   **注意：** 普通 `mergeAll` 通常只保留 position / normal / uv；带 `aFlex` 的布料必须走专用的 `mergeFlex`。

4. **UV**  
   `Geo.worldUV` 保证近似恒定 texel 密度；可选 domain warp 打破世界轴对齐的贴图格子；`uv1` 拷贝供 AO。

5. **顶点色磨损**  
   合并后再写 `color`。约定：**白 = 完好**；着色器侧  
   - **R** = grime（污垢）  
   - **G** = wet（湿感 / 降粗糙）  
   - **B** = edge wear（棱角露出浅色底材）  
   见 `materials.js`。

6. **一桶一 Mesh**  
   `_finalize` 为每个非空桶创建一个 `THREE.Mesh` → **一次 draw**。文档中市场关卡自称约 **~18 draws**；完整 `SURF` 表约 **21** 个键（空桶不产出）。

### 1.2 静态合并 vs 动态系统

- **静态关卡本体**：全部进材质桶合并；运行时网格不变形。  
- **布料 / 部分绳索 / 烟**：单独列表 → `mergeFlex` 保留 `aFlex` → 顶点着色器风动（`applyWind`）。  
- **InstancedMesh**：需要每实例变换/颜色的重复物（货箱、草等），不进静态 merge。  
- **“飘动”不是分桶依据**：市场遮阳篷多为建造时静态下垂；雪原破布才是 `aFlex` 风动。

### 1.3 Draw call 与“~18–20”

| 说法 | 含义 |
|------|------|
| ~18–20 | **关卡静态合并后的材质桶网格数**（市场 `level.js`） |
| 全帧 200–400+ | 另含 props、阴影、粒子、后处理、武器、UI 等 |

分桶的第一准则是**表面/材质语义**；透明、自发光、贴花、自有贴图（如 `distant`）也会单独成桶。

## 2. 美术与技术共同约定

### 2.1 磨损合同（Vertex Wear）

关卡克隆库材质并打开 `vertexColors`，避免污染共享材质。白色顶点表示“未伤”；通道含义见上。湿感与天气湿参数相乘时，仍受顶点 G 通道权限控制。

### 2.2 尺度优先来自几何，其次才是贴图噪声

多个关卡反复验证的同一原则：

- **储油罐**：板层、焊缝、抗风圈、管嘴提供 30–60 m 可读尺度；贴图 meso/detail 刻意压低，避免远距 aliasing。  
- **Bayon 脸**：连续曲面法线 + 凹度烘焙；不用一堆 2–8 cm 台阶盒子（远距变成“希腊回纹”）。  
- **树干**：尖削、倾斜、凹槽、板根改变轮廓；贴图只负责树皮颗粒。

### 2.3 贴图侧（简述）

高度优先流程：seed → 噪声族（fbm / worley / ridged / drip / shear）→ recipe 填 `Surf` → 可选 deband → emit（AO、Sobel 法线、ORM）→ `DataTexture`。几何管线消费这些材质，但**几何轮廓不能靠贴图伪装**。

## 3. 树干（Jungle）

**源码：** `level_jungle.js`（`stations` → `tube` → `barkTube` → `buttressFin` → `buildTree`）  
**Demo：** [tree_trunk/index.html](tree_trunk/index.html)

### 3.1 算法步骤

1. **参数与轴线**  
   高度 `h`、基准半径 `r`、倾斜 `lean`。轴线用二次倾斜（越高越偏），避免“铅垂水管”。

2. **站点 `stations`**  
   沿高度采样 `[x,y,z,r]`。半径尖削（根粗顶细）；`fbm` 扭摆打破直线。

3. **半径圆盘**  
   每站以局部切向为法向画截面圆，即管的骨架尺寸。

4. **局部标架 N / B / T**  
   `T` 由邻站差分；`N = normalize(up × T)`，竖直段换参考轴防退化；`B = T × N`。

5. **截面环顶点**  
   `p = centre + (N cosθ + B sinθ) · r`。

6. **扫掠 `tube()`**  
   相邻两环四边形 → 两三角 = 管壁。变半径、可弯曲的几何原子。

7. **纵向凹槽 flute（`barkTube`）**  
   角向调制半径：`rr *= 1 + flute · (sin(θ·lobes)…)`，形成 3–6 道纵棱。

8. **板根 `buttressFin`**  
   径向曲线挤成薄鳍，绕树干旋转；上缘贴干、外端落地。

9. **拼装**  
   全部进 `bark` 材质桶，关卡 finalize 时与其它树干合并。叶冠另路 InstancedMesh。

### 3.2 Demo 说明

左侧步骤列表 + 公式，右侧 Three.js wireframe。支持上一步/下一步、自动播放、重置视角；拖拽旋转、滚轮缩放、方向键切换。共 9 步，忠实复现 jungle 树干拼装。

**相关变体：** ruins 用 `limb()`；snowbound 简单树干可用 `cyl`。

## 4. 布料与风动（Snowbound）

**源码：** `props_snowbound.js` — `K.sheet`、`_clothPart`、`mergeFlex`、`applyWind` / `WIND_BODY`  
**Demo：** [cloth/index.html](cloth/index.html)

### 4.1 主样本：栅栏迎风破布

`K.sheet(w, d, sag, nu, nv, pin, noise)`：

1. **UV 网格** — `(nu+1)×(nv+1)` 参数平面铺成矩形。  
2. **`pin(u,v)`** — 钉住权重；迎风上缘钉死，下摆自由。示例：`saturate(1.35 − v·1.8)`。  
3. **静态下垂** — 仅 `slack = 1−pin` 区域 sag（噪声 + 正弦），写入 rest pose。  
4. **`aFlex = slack²`** — 风能动多少；平方让过渡更陡。  
5. **三角化** — 标准格子两三角。  
6. **`_clothPart`** — 不进静态桶，带世界矩阵进入 `clothParts`。  
7. **`mergeFlex`** — 按 kind 合并并**保留 `aFlex`**（`mergeAll` 会丢掉）。  
8. **`applyWind`** — `onBeforeCompile` 链式注入，不破坏 materials 的 wear/triplanar。  
9. **每帧** — 更新 `sbTime` / `sbWind` / `sbWindDir`；振幅与频率随 `windSpeed` 同升。

### 4.2 风动公式（要点）

- 世界位置相关的慢包络 gust + 快涟漪，避免全村同相。  
- `sbA = amp · aFlex · gust`  
- 位移：**顺风推住** + 振荡（不是对称摆动）。  
- `transformed.x/z` 跟风向；`y` 有 billow。

### 4.3 对比样本

- **冷冻衣物 `frozenGarment`**：硬板感，`aFlex` 随高度微弱，不宜当主教学路径。  
- **市场遮阳篷**：多为静态 sag，进 `fabric` 桶，**不是** snowbound 风动。

### 4.4 Demo 说明

9 步 wireframe；左侧风速滑条与「风动」开关；后期步骤用与源码一致的顶点位移 Shader 驱动。颜色图例区分 pin / aFlex / 风向。

## 6. 储油罐（Refinery Tank Farm）

**源码：** `level_refinery.js` → `buildTanks()`（T1：r=14.5 m，h=12.5 m）  
**Demo：** [oil_tank/index.html](oil_tank/index.html)

### 6.1 设计意图

罐区是与工艺区完全不同的空间：巨大平滑曲面、下凹围堰、开阔天空。尺度必须来自**真实结构几何**，不能依赖亚像素噪声（远距会变成 cottage cheese）。

材质桶 `tank`：`base: painted_metal`，`uv` 高，但 **meso / detail / grain 刻意压低**；`albedoTarget` 约老化漆灰。

### 6.2 拼装步骤

1. **规格** — 半径、高度、板层数 `nc = max(4, round(h/2))`，径向分段约 40。  
2. **板层筒壁** — 每 ~2 m 一层开顶圆柱；`rr = r + (nc−c)·0.006` 下厚上薄。  
3. **水平焊缝环** — 层间凸环（焊帽尺度，远距可读）。  
4. **竖向对接焊** — 按约 11 m 板宽均分；隔层错半板，避免竖缝贯通。  
5. **底部管嘴** — 加强垫 + 短管 + 法兰螺栓（眼高细节）。  
6. **抗风圈** — 顶部环廊格栅 + 斜撑 + 栏杆（大型储罐标志特征）。  
7. **屋顶** — 浅锥壳 + 量油口 / 通气 / 泡沫管 / 内沿栏杆。  
8. **螺旋梯** — 约 46 级格栅从围堰到抗风圈。  
9. **围堰 bund** — 钢筋混凝土墙（模板板、拉杆塞、压顶、跨步梯）+ 完整拼装。

另有管线出口、钠灯、屋顶障碍灯、罐号/易燃贴花、源自焊缝的流挂 streak 等。

### 6.3 Demo 说明

按比例缩小的 wireframe 分步；颜色区分板层 / 焊缝 / 竖焊 / 管嘴 / 抗风圈 / 屋顶 / 螺旋梯 / 围堰。交互同树干页。

## 7. Bayon 雕像人脸（Ruins）

**源码：** `level_ruins.js` — `faceMask`、`faceHeight`、`carvedFace`、`faceTower`、`_paint` 的 `faceTag`  
**Demo：** [bayon_face/index.html](bayon_face/index.html)

### 7.1 为何不能用盒子堆

早期用几十个轴对齐盒子拼眉、眼、嘴。在约 21 m 的签名构图下，每块只有厘米级台阶，透视后变成**水平分带的建筑线脚**，被评成“希腊回纹 / 台阶饰物”。  
人脸应是**连续曲面**：法线扫过天光半球产生明度梯度；平面在任何浮雕深度下都做不到这一点。

### 7.2 高度场模型

参数：`u ∈ [-1,1]`（半宽归一化），`v ∈ [0,1]`（下巴→冠顶）。  
解剖标尺（v）：

| v | 部位 |
|---|------|
| 0.03 | 下巴 |
| 0.22 | 嘴 |
| 0.36 | 鼻根 |
| 0.52 | 眼 |
| 0.61 | 眉 |
| 0.75 | 头冠带 |
| 0.97 | 冠顶 |

眼心约 `|u|=0.345`（头宽五分法）。**注意 u/v 单位不同**：石头上的“圆”在参数域里 v 半径约为 u 的 0.545 倍。

### 7.3 算法步骤

1. **`faceMask(u,v)`**  
   超椭圆头形 + 耳 / 耳垂叶瓣。`mask≤0` 的四边形不发射 → 网格边界即剪影。

2. **`faceHeight` 体量**  
   高原 + 穹顶：`z = 0.36 + 0.60·core^0.46`；颊垫、下巴垫；额略后倾。安详 = 大片平滑面。

3. **五官层**  
   - 眉脊 + 下切（不是横条）  
   - 闭眼：眼窝凹陷 + 杏仁睑 + 睫毛刻线（0.0135 v）  
   - 宽鼻：尖约 0.58 dp 前突  
   - 微笑：嘴角仅抬约 0.030 v（~16 cm）；更大则成咧嘴  
   - 头冠 band（非一排尖齿）

4. **风化**  
   fbm 微起伏；剥蚀用 `keep` 避开五官，否则“五官全被吃”只剩石头。

5. **采样成网**  
   `NU/NV` **按脸尺寸**取下限（≥68×72），使刻线约占一格。固定 texels/m 会让小脸丢嘴。  
   `zz = back + (fz−back)·smooth(mask)`，背平面埋入塔身。

6. **局部凹度**  
   `cav = boxBlur₂(hz) − hz`。唇缝/睫毛与颊同绝对深度，深度 AO 看不见；凹度写入 `faceCav`。

7. **材质分裂**  
   主体 `sandstone`；边缘斑驳 `mossy`。**不再**把凹度四边形拆进 `carve` 桶（曾造成虚线刻痕）。

8. **`faceTag` 烘焙（`_paint`）**  
   相对前平面 `F=1.0·dp` 的深度 AO + 凹度 + 侧缘/下缘；proud（负凹度）走淡色棱角磨损。  
   深切靠**反照率/烘焙**变暗，不指望天空投射阴影。

9. **上塔 `faceTower`**  
   第 2（及可选第 3）层四面各一脸；登记在层脚最宽处，使下巴也伸出锥形塔身；浅浮雕约 `fw·0.160`。冠用 frustum 盒子做天际剪影。

成本量级：中央大脸约数千三角；全关卡约 24 张脸进已有石材桶，**零额外 draw**。

### 7.4 Demo 说明

逐步打开高度场特征层；展示 mask 轮廓、凹度高亮、边缘苔藓与冠。交互同其它 wireframe demo。

## 9. 算法族对照

| 族 | 代表 | 核心手段 | 成功判据 |
|----|------|----------|----------|
| 扫掠管 | 树干、部分肢体 | 站点 + 标架 + 截面环 | 轮廓尖削/弯曲可读 |
| 参数布 + 顶点属性 | 破布 | pin / sag / aFlex + VS 风 | 钉住不动、自由角顺风 |
| 材质桶合并 | 市场关卡 | SURF 键 → mergeAll | ~18–21 次关卡静态 draw |
| 结构叠层圆柱 | 储油罐 | 板层 + 焊缝网格 + 附件 | 远距仍有尺度，不靠噪声 |
| 标量高度场 | Bayon 脸 | f(u,v) + mask + 凹度烘焙 | 安详五官在天光下可读 |
