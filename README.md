# 算法即场景：学习 Claude-of-Duty

![算法即场景 · 从零资产到可玩的世界](images/slide01-1.webp)

本仓库是引擎 PCG 团队学习 [Claude-of-Duty](https://github.com/mshumer/Claude-of-Duty) 的技术分享。整个分享基于 TA 同学 kelvin 对 Claude-of-Duty 的完整复刻经验（[operation-blackout](https://github.com/kelvincai522/operation-blackout)），以及对生成过程、生成算法、Build-Critic-Fix 审查流程、单一随机数种子等各项内容的调研和思考。

打开 [`index.html`](index.html) 即可阅读网页版讲义（含演讲实录与交互演示）。

在线阅读：[https://kilia.github.io/learn-claude-of-duty/](https://kilia.github.io/learn-claude-of-duty/)
